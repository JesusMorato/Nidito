# Nidito

Las casas en venta que nos interesan, en un mapa y en una lista, valoradas a dos.

App web para una pareja: cada casa entra a mano, pegando el texto del anuncio o
compartiendo un enlace desde el móvil; queda en un mapa con su precio y en una lista
que se ordena y filtra como queráis; y cada uno la puntúa por aspectos con estrellas
y ve lo que ha puesto el otro.

- Web: https://jesusmorato.github.io/Nidito/
- Plan de producto: [`docs/PLAN.md`](docs/PLAN.md)
- Estado y decisiones: [`docs/README.md`](docs/README.md)
- Puesta en marcha (Supabase, secrets, Pages): [`docs/CONFIGURACION-MANUAL.md`](docs/CONFIGURACION-MANUAL.md)

Hermana de [GasTitos](https://github.com/JesusMorato/GasTitos): mismo esqueleto (Vue 3 +
Supabase + GitHub Pages), mismo hogar de dos con código de invitación.

```
npm install
npm run dev
npm test
npm run build
```
